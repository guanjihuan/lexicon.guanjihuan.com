# 文档导航

本目录存放**当前有效的使用与维护文档**；[CHANGELOG](../CHANGELOG.md) 保存逐轮历史记录。历史章节是当时的快照，不随现状回写。

## 按需求查阅

| 需求 | 文档 | 内容 |
|---|---|---|
| 了解项目、启动网站 | [项目 README](../README.md) | 功能概览、快速开始、常用入口 |
| 使用学习网站 | [使用指南](user-guide.md) | 浏览、搜索、学习、测验、统计、快捷键与本地数据 |
| 修改词条或例句 | [数据与生成流水线](data-pipeline.md) | 真源与生成物、编辑顺序、编号与分类口径、质量闸门 |
| 运行回归测试 | [测试与巡检](testing.md) | 测试矩阵、浏览器配置、变异测试与人工审读盲区 |
| 查找文件或清理产物 | [项目结构](project-structure.md) | 运行文件、数据、工装、留档脚本与临时目录的职责 |
| 提交改动或更新文档 | [协作与文档维护](contributing.md) | 多窗口协作、暂存边界、CHANGELOG 编号与文档同步清单 |

## 推荐阅读顺序

- **使用者**：项目 README → 使用指南。
- **内容维护者**：数据与生成流水线 → 测试与巡检 → 协作与文档维护。
- **前端或工装维护者**：项目结构 → 测试与巡检 → 协作与文档维护。
- **排查历史决策**：先在 CHANGELOG 文首看当前状态，再按节号或关键词搜索正文；不要拿历史节的旧数字覆盖当前文档。

## 文档维护原则

1. **一类事实只设一个主要归属地**。使用说明放在使用指南，生成顺序放在数据流水线，测试职责放在测试文档；其他页面用链接指向，不复制成长段。
2. **当前文档与历史记录分开**。当前规则可修订；CHANGELOG 已发布的历史正文不改写，只追加新节。
3. **派生数字必须实测**。词数、分类数、例句数和断言数从当前产物或测试实跑结果取得，不由旧数字心算推导。
4. **少写容易漂移的字面量**。测试文档不钉死断言总数；确需写词库规模时，同步检查 README、CHANGELOG 文首和页面元信息。
5. **链接必须可用**。新增或移动文档后检查相对链接；本目录中的仓库根目录文件使用 `../` 前缀。
6. **临时交接不等于项目文档**。根目录 `HANDOFF-*.md` 被 `.gitignore` 排除，只供当次交接使用，不作为现行规则来源。

## 改动后的同步清单

| 改动类型 | 至少检查 |
|---|---|
| 词条增删、核心层或分类变化 | 数据流水线、README 顶部规模、CHANGELOG 当前状态、相关页面静态文案 |
| 新增或调整生成器 | 数据流水线的真源表与执行顺序、项目结构 |
| 新增、删除或改名测试 | 测试矩阵与命令、项目结构；不要沿用旧断言数 |
| 页面功能或快捷键变化 | 使用指南、README 功能概览；必要时更新页面内说明 |
| 文件或目录移动 | 项目结构、所有相对链接、脚本中的路径引用 |
| 协作流程变化 | 协作与文档维护、README 入口 |
| 任何已落地改动 | 按仓库约定追加 CHANGELOG；历史正文保持不动 |
