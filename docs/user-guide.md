# 使用指南

GUAN 学术英语词汇库是一个纯前端学习网站。每词提供中英释义、词性与色彩标签、3 条中英对照例句和词典外链；学习进度只保存在当前浏览器中。

## 启动与离线使用

任选一种方式：

1. 直接用现代浏览器打开仓库根目录的 `index.html`，`file://` 方式即可完整运行；
2. 在仓库根目录运行静态服务器：

   ```bash
   python3 -m http.server 8000
   ```

   然后访问 <http://localhost:8000>。

无需构建，也无需安装前端依赖。发音使用浏览器和操作系统提供的语音包，不依赖项目服务器。

## 首页

首页集中显示：

- 已掌握、学习中、待复习、收藏和连续学习天数；
- 今日目标进度；
- 复习预报：未来 48 小时内及未来 7 天内将到期的词；
- 随机一词：每次打开或刷新随机抽取，也可点面板右上角“刷新”手动换词；
- 最近测验记录。

顶栏右上角徽标显示**最近 30 天访问本站的次数**。每次打开或刷新计一次，连开两个标签页就是两次；该计数与“连续学习天数”不是同一指标。

## 词库

### 搜索、视图与学习入口

词库支持全量浏览、中英文搜索、排序、分页和打印清单。搜索覆盖词形、释义与全部例句；只命中例句的结果带“例”徽标。

三种视图：

- **表格**：适合对照编号、词形、释义和标签；
- **卡片**：适合阅读例句；
- **按词性分组**：按形容词、副词、动词、名词、连词分节，形容词、名词、动词再按感情色彩细分；介词与介词性固定短语归到末尾“介词”一节。

可从当前筛选结果直接开始学习，也可打开单词详情、收藏单词或跳转词典外链。

### 五组正交筛选

| 维度 | 档位与口径 |
|---|---|
| 词性 | 形容词、副词、动词、名词、连词，以及“介词”（单词介词与介词性固定短语） |
| 是否核心 | 是 / 否 |
| 感情色彩 | 积极的、消极的、争议性的、中性的，以及“其他”（未标注褒贬色彩的词） |
| 语体色彩 | 学术术语、书面语、口语、中性；全库每词都有值 |
| 首字母 | 按词形首字母筛选 |

另可按学习状态筛选。每个维度都可独立组合，每一维各档之和等于该维“全部”的条数。

筛选选项旁的数字表示：**保持其他筛选条件不变，选择该档后还剩多少词**。它不是全库静态总数；搜索词或其他筛选变化时会同步重算。

感情色彩只挂在形容词、名词、动词三类实词上。词性锁到副词、连词或介词时，四个带标签的感情档显示 0 并灰显，“其他”对应该词性的全体；这一排不会整行消失，以免筛选状态难以理解。

“学术术语”指某学科的专门技术词，“书面语”指正式文体标志，两者不是同一维度下的混合标签。详细分类与介词口径见[数据与生成流水线](data-pipeline.md#关键内容与分类口径)。

## 全局搜索

按 `/` 唤起全局搜索，可搜词形、中文释义、原号和例句。

结果按命中强度排序：

```text
词形全等 > 词形前缀 > 词形包含 > 编号 > 释义 > 仅例句
```

每条结果尽量显示实际命中处：释义命中显示对应释义，例句命中显示带高亮的例句片段。浮层最多列 12 条；结果更多时，使用“在词库中查看全部 N 个结果”进入可分页、可继续筛选的词库视图。

## 学习

学习与测验位于同一页，通过页首“学习 / 测验”分段切换。

### 今日目标与推荐

页首先显示与首页同口径的今日目标：已学次数、目标、还差次数和连续天数。进入页面时，系统按以下优先级替你预选好推荐范围（选中高亮落在范围 chip 上）：

```text
到期 > 未学习新词 > 学习中 > 已掌握
```

### 范围与每次上限

范围面板分为“范围 / 词性 / 每次上限 / 本次”四排。牌组选项显示名称与词数；空范围显示“0 词”，并在悬停和读屏说明中给出“暂无到期”“还没收藏”等原因。

点牌组选项只**选中**该范围（高亮并在“本次”一行给出摘要），按“开始学习”确认后才开卡——与测验面板“选范围 → 开始测验”是同一套两步流；误点不会直接开局。全页只有“本次”行那一颗“开始学习”按钮；上次开卡的范围仍在时，预选中跟随上次的范围，否则落在推荐范围上。

每次上限提供 10 / 20 / 30 / 50 的快捷档位，也可在数字框中自定义；“本次”摘要中的张数会随上限与所选范围实时更新。选中空范围时说明原因并禁用开始按钮。从词库“学习当前筛选”进入时，该范围也会保留在面板中。

会话进行中也提供“换模式”入口，不必先退出再切换学习与测验。

### 卡片与间隔重复

卡片采用莱特纳五盒间隔重复，翻卡后可按“忘了 / 模糊 / 认识”评分。触屏设备翻面后可右滑表示“认识”、左滑表示“忘了”；可在设置中关闭手势。

翻面后，卡背直接摊开整条词条：

- 分条编号的中文释义；
- 词性与感情色彩标签；
- 全部 3 条中英对照例句；
- 备注与三个词典链接；
- “不认识 / 学习中 / 已掌握”手动标记按钮。

卡高随内容伸缩；窄屏改为单栏并由页面滚动，不需要再打开一层弹窗。

## 测验

五种题型可单独或混合出题：

1. 看词选义；
2. 看义选词；
3. 拼写填空；
4. 听音辨词；
5. 例句挖空——从该词例句中挖掉目标词，再选择正确词形。

设置分为“题型 / 范围 / 题数”三排，“本次”一行说明实际出题范围和张数。范围词数不足或题数超过可用范围时，界面会明确提示。

支持错题回顾与一键重测错题。没有可用英语音色时，听音辨词禁用，混合题型也不会抽到它。

## 收藏与统计

- **收藏**：任意词条可一键收藏；可按收藏范围学习或测验，也可导出纯文本清单。
- **统计**：掌握进度环、记忆等级分布、120 天活跃热力图、按词性掌握分布、按首字母覆盖和测验历史。

## 设置、发音与例句

设置页提供浅色 / 深色主题（默认深色）、朗读语速、每日目标、JSON 数据导出 / 导入和重置。「恢复默认设置」一键把主题、语速、目标、上限与各开关回拨到出厂值，学习进度 / 收藏 / 测验记录等数据不受影响。

发音遵循“点哪读哪”：只有点击喇叭或“朗读”按钮才发声；学习自动朗读可在设置中打开，默认关闭。系统必须检测到英语音色才朗读英文，没有英语语音包时给出安装提示，不拿中文等其他语言音色兜底。

每词 3 条例句显示在词条详情、学习卡背、词库卡片视图和打印清单中。

## 快捷键

完整清单也可见于设置页的“键盘快捷键”一节。

| 场景 | 快捷键 |
|---|---|
| 全局 | `/` 搜索；`Enter` 打开词条；`Esc` 关闭；`?` 显示 / 隐藏快捷键说明 |
| 翻卡学习 | `空格` 翻面；`1 / 2 / 3` 忘了 / 模糊 / 认识；`S` 收藏；`P` 朗读；`U` 撤销上一次评分 |
| 测验 | `1–4` 选择答案；`空格` 下一题 |
| 词库 | `← / →` 翻页 |
| 词条弹窗 | `← / →` 切换上一条 / 下一条 |

## 本地数据、备份与隐私

学习进度、收藏、设置和访问统计均保存在浏览器 `localStorage`，主存档键为 `wl_state_v1`，不会上传到项目服务器。

换浏览器或换设备前，请在设置页**导出 JSON 备份**，再到目标环境导入。重置会改变本地学习数据，操作前应确认已有备份。

词条内容以词形关联例句，以原始编号关联本地学习进度；因此维护者不能随意重排编号。普通使用者无需直接编辑这些标识。
